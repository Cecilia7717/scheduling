Experiment 2: Why MaxFlow-Passes Is Faster
==========================================

Configuration
-------------
Seed: 42
Instances: 30
Timing repeats per solver per instance: 20
Jobs: 35-50
Horizon rule: horizon = 6 * number_of_jobs
Green share range: 0.7500-0.8000
Brown share range: uncontrolled/random split of non-green time
Target utilization range:
    0.8500-0.9000

Algorithms
----------
1. MaxFlow-Passes-Reuse
   Same residual graph is retained across green -> brown -> red.

2. MaxFlow-Restart
   Same pass logic, but the flow network is rebuilt and solved from zero
   at every carbon level.

3. Pure-MinCostFlow
   Direct min-cost flow baseline.

Average Runtime
---------------
MaxFlow-Passes-Reuse: 7.594677 ms
MaxFlow-Restart:      15.789238 ms
Pure-MinCostFlow:     37.662060 ms

    2.029810x

    4.919448x

Correctness
-----------
All three methods are required to be feasible on every generated instance.
The script also checks that all three exact methods return identical
normalized carbon cost for every instance. A mismatch aborts the run.
